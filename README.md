# Montablate 2.0 (mb2)

Grimdarkowa gra w stylu Mount & Blade: Warband, w klimacie moda World of Vasnar (nekromancja, potwory, pogańskie kulty, gotyk z późnym średniowieczem). Własny silnik WebGL2 w TypeScript, low-poly „hybryda fasetowa” w duchu PS1/PS2, cała grafika generowana w kodzie.

- Dla AI i nowych czatów: **[CLAUDE.md](CLAUDE.md)**, potem **[docs/](docs/README.md)**.
- Zagraj: otwórz `dist/mb2-build-N.html` (najwyższe N) w przeglądarce.
- Zbuduj: `npm i && npx tsc -p . && node build.mjs game N`.
